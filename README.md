# Blocking Fake Anonymous Scammer Bots on Facebook (aka Fake Anonymous Collective Scammer Bots)

**Helping Anonymous-type pages stop fake Anonymous Collective scammer bots and fixed-betting / membership scams**

![Broken scammer bot repeating "My network was block totally"](./images/broken-scammer-bot.jpg)

## The Problem

The Anonymous page I co-own has been targeted by fake Anon (aka Anonymous Collective) scammers for a long time. These accounts:

- Reply to fans’ comments
- Use scam-style profile names
- React to posts and comments
- Leave comments praising Anonymous for “fixed games”
- Harass fans in DMs
- Sell fake “Anonymous membership”

**Important**: Anonymous has no members. It is an idea, not a club you can join.

These scammers run sophisticated “fixed sports betting” scams. They post fake game results and steal money from victims. Some fans have mistakenly believed the real page was involved — we do **not** run any scams.

## The Solution

Over the past year we have been adding banned keywords and keyphrases to Facebook’s AI Assist (Moderation Assist / Hidden Words). Comments containing these phrases are automatically flagged and hidden.

The keywords are things no legitimate user would ever say (e.g. “send us a direct message”, “special fixed games”).

After the latest round of additions, some of the bots are now broken. The screenshot above shows one bot stuck repeating:

> My network was block totally

These comments were liked by a different scammer whose own comment had already been auto-hidden.

**We have successfully broken the fake Anon (aka Anonymous Collective) scammer bots… for now.**

This repository is for documentation and raising awareness only. No self-promotion intended.

## How to Add the Keywords

### For Facebook Business Pages / Professional Dashboard (Moderation Assist)

1. Switch into your Page.
2. Open the **Professional dashboard** (Business Dashboard or Creator Dashboard).
3. Go to the **Engagement** tab → **Tools** → **Moderation Assist**.
4. Tap **Add** in the “Manage comments” section.
5. Select **Keywords in comment** (or the custom keywords option).
6. Paste the keyword list (comma-separated or one per line, depending on the interface).
7. Save / Add to Moderation Assist.

You can also add other criteria (no profile picture, new accounts, links, etc.).

Official help: [Manage comments with Moderation Assist](https://www.facebook.com/business/help/1753036688579904)

### For Personal Profiles (or simple keyword hiding on Pages)

1. Click your profile picture (top right).
2. Select **Settings & privacy** → **Settings**.
3. In the left menu, click **Followers and public content**.
4. Under “Viewing and sharing”, select **Hide comments containing certain words from your profile** (or “from your Page”).
5. Paste the keywords (comma-separated).
6. Click **Save**.

Official help: [Block words from comments](https://www.facebook.com/help/1182883832161405)

## Notes

- Hidden comments are still visible to the commenter and their friends.
- Facebook automatically covers common variations, misspellings, and symbol substitutions.
- Review the Activity Log / hidden comments occasionally to catch false positives.
- Scammers evolve — keep updating the list.

Stay safe, and share this with other Anonymous-related pages.
